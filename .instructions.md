# Usage
This custom agent is optimized for the `v0-vesselsurge` repository and OpenClaw deployment tasks.

Use it when you need help with:
- code changes in `app/`, `components/`, `lib/`, or `hooks/`
- Next.js, React, TypeScript, Supabase, or maritime-data integration
- deployment configuration and OpenClaw workflow
- fixing issues in `deploy_vesselsurge.sh` or the OpenClaw workspace linkage
- troubleshooting GitHub Actions or Vercel deployment runs

# Best prompts
- "Update `deploy_vesselsurge.sh` for OpenClaw deployment."
- "Fix the dashboard page rendering issue in this repo."
- "Review the OpenClaw deployment path and workspace integration."
- "Help me extend the maritime search API in this project."

# When not to use
- general questions unrelated to this repository
- product brainstorming outside the codebase
- external API research or deployment credential management
